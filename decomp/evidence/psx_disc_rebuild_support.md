# PSX Disc Rebuild Support

This note records the first working local disc-image rebuild path for the USA
workspace.

## What works

- [`../verification/build_psx_disc_image.ps1`](../verification/build_psx_disc_image.ps1)
  rebuilds a `BIN/CUE` with `mkpsxiso` using the local clean retail image as
  the template source of truth.
- The script caches a `dumpsxiso` template under `.codex_tmp/psx-disc-rebuild`
  and reuses the dumped `license_data.dat`.
- The script prefers files from [`../../Game Data`](../../Game%20Data) when
  they exist and falls back to the cached clean dump when they do not.

## Current command

```powershell
powershell -ExecutionPolicy Bypass -File "decomp/verification/build_psx_disc_image.ps1" `
  -OutputDirectory ".codex_tmp/psx-disc-rebuild/output-test" `
  -SkipDifferenceScan
```

## Observed result on 2026-05-11

- Clean source BIN:
  `Game Data/Vagrant Story (USA).bin`
- Rebuilt BIN:
  `.codex_tmp/psx-disc-rebuild/output-test/Vagrant Story (USA) patched.bin`
- Clean SHA256:
  `81D6D698FE953DAF8C6EABBAAD6610664C17529DC3322A44353C7EDFAFD6D566`
- Rebuilt SHA256:
  `71C51AF110C6D76D42F14B224F4416729BA4F96B0FC165CCE4B7AF6D3E156641`
- Image sizes match at `750643152` bytes.
- The rebuild is not byte-identical to retail, so this is a practical rebuild
  path rather than a perfect round-trip.

## Current fallbacks

The local extracted tree is not yet `mkpsxiso`-ready for every streamed media
asset. The current successful run fell back to the cached clean dump for:

- `MOV/TITLE.STR`
- `ENDING/ENDING.XA`

## Implications for patching

- This is enough to produce a rebuilt modded image for emulator testing.
- A future `PPF` can be generated by diffing the clean retail `BIN` against the
  rebuilt modded `BIN`.
- Because the rebuild is not byte-identical even before mod edits, the patch
  will include both intentional file edits and toolchain/layout deltas unless a
  more exact rebuild route is found later.
